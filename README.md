# 秋葉原・上野 カードショップ地図デモ

架空の9店舗を使った、店舗検索と地図表示のサンプルです。実店舗の案内には使えません。

- 店名・エリアで切り替えて検索し、店舗タイプで絞り込めます。
- 店舗管理画面で追加・編集・削除、JSONでバックアップ・復元できます。変更は同じブラウザにだけ保存され、他の端末とは共有されません。
- Google マップは外部リンク（位置・徒歩ルート）のみ。埋め込みや API キーは使いません。

## ローカルで開く

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザで `http://127.0.0.1:8000/` を開きます。

## 確認

```sh
node test-store.js
```

店舗データをCSVから再生成する場合は `node build-data.mjs`。追加の画面テスト `test-browser.cjs` には Playwright と Chromium が必要です。テストでは外部地図は読み込みません。
